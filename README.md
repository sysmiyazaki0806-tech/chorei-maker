# 朝礼メーカー v1.2（2026-08-16）

**セナさん個人用**。参考: TikTok @lenovovovovo の「Gemini Canvasでしゃべる解説動画」手法を単一HTMLで実装したもの。
**index.html をブラウザで開くだけ**で動く（外部ライブラリ・APIキー・ネット不要）。

## セナさん（iPhone・スマホのみ）向けの注意
- iPhoneのSafariは全画面APIが無いため、「全画面（収録用）」は自動で**シアターモード**（画面いっぱい表示・UI非表示・右上✕で戻る。✕は再生中は自動で消える=収録に映らない）になる
- **横の消音スイッチがONだと声が出ない**（ページ内tipsにも記載）
- LINEでHTMLファイルを直接送るとiPhone側でJSが動かない可能性が高い（QuickLookプレビュー）→ **GitHub PagesでURL化してSafariで開いてもらうのが確実**（公開は宮崎さんの承認待ち）
- 台本の編集内容は端末（ブラウザ）ごとに保存される

## キャラ「ハヤト」について（重要）
**ハヤトは人型にしない**（宮崎さん指示 8/16）。ビジュアル＝**青く光る結晶（宝石）**。
しゃべっている間はコアの明滅＋光線のゆらめきで表現（口パクの代わり）。アイドル時は浮遊＋時々きらめき。

## できること
- 内蔵キャラ「ハヤト」（光る結晶SVG）がブラウザ音声合成で台本を読み上げ
- 字幕同期（白文字黒フチ・スマホ可読）／スライド自動送り／現在行ハイライト
- 今日の日付・曜日を台本に自動差し込み（`{{date}}` `{{youbi}}` `{{time}}`）
- 台本編集画面つき（`# タイトル`＋行=セリフ。localStorageに自動保存）
- 縦(9:16 TikTok用)／横(16:9)切替、全画面（収録用）、声の選択・速さ調整
- 音声が使えない端末でも文字数ベースで自動進行（止まらない）

## 動画への書き出し
全画面 → 画面収録（iPhone:コントロールセンター / Win:Win+G）→ 再生 → 停止。

## 自前キャラ画像に差し替える
1. 立ち絵PNG（正面・口がはっきり見えるもの）を同フォルダに置く
2. index.html 内 `CONFIG.imageSrc: 'ファイル名.png'` を設定
3. `CONFIG.mouth: {x,y,w,h}`（画像に対する口領域の比率）を数値で微調整
   - 口の位置がずれる → x/y を少し増減
   - 口の開きが大きい → コード内 `flapImageMouth` の `0.5` を小さく

## 調整ポイント
- 左上の帯の文字: `CONFIG.brand`
- 口パク間隔: `CONFIG.flapMs`（既定120ms）
- 終了カードの文言: HTML内 `#endCard .big`
